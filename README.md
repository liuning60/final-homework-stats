# 期末作业统计工具

一个单文件网页工具：把学生交的作业文件夹拖进来，几秒内算出「每个学生每个作业交了没交」，顺手生成缺交名单。

不需要安装任何软件，不需要命令行，也不需要先在文件夹里生成什么清单文件。

## 怎么用

1. **贴名单**：在 Excel 里框选姓名那一列（连学号一起复制也行），Ctrl+C，粘到左边框里。
2. **给目录**：点「选择作业文件夹」选作业根目录，或者直接把文件夹拖到页面任意位置。
3. **看结果 / 导出**：自动出统计卡片、明细表、缺交名单和异常文件；点「复制缺交名单」发群里，或导出 Excel / CSV。

## 它做了什么

- **按子文件夹自动分作业**：根目录算一列，每个子文件夹算一列；点列名可以改名。
- **区分成片与工程文件**：mp4 / mov 等算成片，prproj / aep 等算工程文件，同一个作业交了两个文件不会被算成两份。
- **自动纠正放错位置**：文件名里写了别的作业文件夹的名字，会自动归到那个作业，并标注「放错目录」。
- **异常检查**：没对上任何姓名的文件、只有工程文件没有成片、同名多版本、学号与名单不符、文件过小（疑似占位）都会单独列出来。
- **学号校验**：名单里带学号时，会用文件名里的学号校验，姓名写错、学号写错都能看出来。
- 名单和列名记在浏览器本地，下次打开还在。

## 隐私

所有计算都在你自己的浏览器里完成，页面不联网、不上传任何文件，只读取文件名、大小和修改时间，不读文件内容。

## 浏览器

推荐 Edge 或 Chrome（近两年的版本都可以）。Safari 对「整目录读取」支持较差，拖拽可能不可用，只能用「选择作业文件夹」。

## 建议的目录与命名习惯

- 每个作业建一个子文件夹，文件夹名就是作业名；
- 文件名里写清顺序号、作业名、学号和姓名，例如 `001_作业名_202500001张三.mp4`。

这样作业列会自动分开，学号还能反过来校验姓名有没有写错。
